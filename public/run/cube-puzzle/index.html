Play Rolling cube puzzle (Cube) online Works — plays right here, unlimited puzzles

Guide updated October 2026 · Runs via WebAssembly (native port)

Cube is a rolling puzzle. A cube sits on a 4x4 grid with six blue squares. Each move tips the cube over one edge onto the next square, and the face touching the floor swaps colour with the square beneath. Collect all six blue squares on the cube's six faces in as few moves as you can. The puzzle is ready below; use the arrow keys to roll.

How to play

  • Each move rolls the solid over one edge onto a neighbouring square.
  • When it lands, the bottom face and the square under it swap colours: a blue square is picked up by a plain face, and a blue face drops its colour onto a plain square.
  • You win when every face of the solid is blue.
  • Try to finish in as few moves as possible; the move count is shown.

Sizes and difficulty

The Type menu offers the Cube on a square grid, and a Tetrahedron, Octahedron and Icosahedron that roll on triangular grids. Each solid needs as many blue squares as it has faces. Custom sets the solid and the grid dimensions.

Solving tips

Plan in pairs of moves: rolling forward and back returns the cube to the same square with the same face down, so you can drop a blue face and pick it up again. Keep track of which faces are already blue; landing a blue face on a blue square swaps blue for blue and changes nothing. Approach the last blue squares so that a plain face is the one landing on them.

Where this puzzle comes from

Cube is part of Simon Tatham's Portable Puzzle Collection, a set of about forty logic puzzles written by Simon Tatham and contributors and released under the MIT licence. Every grid is generated on the spot, so the supply never runs out, and for the grid-logic puzzles the generator makes sure each has exactly one solution, reachable by reasoning rather than guessing. The version here is the collection's own code compiled to WebAssembly; the Game menu can save a puzzle to a file and load it again, and the Type menu changes the size and difficulty.

Frequently asked questions

Is there a Solve option for Cube?

No. Cube does not support Solve, because the point is to finish in as few moves as you can rather than to reach a fixed answer.

Where does the game come from?

Simon Tatham based it on a Java game by Paul Scott and added the triangular grids with the tetrahedron, octahedron and icosahedron.

Is Cube free to play here?

Yes, with no limit on the number of puzzles. Cube is open-source software under the MIT licence, and every grid is generated fresh when you press New game.

Does it work on a phone or tablet?

Yes. A tap works as a click and the puzzle resizes to fit the screen. Puzzles whose controls use the right mouse button are easier with a mouse.
