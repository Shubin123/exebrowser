Play Light flipping puzzle (Flip) online Works — plays right here, unlimited puzzles

Guide updated October 2026 · Runs via WebAssembly (native port)

Flip is a light-switching puzzle. The grid is a mix of light and dark squares. Clicking a square toggles it, and also toggles a fixed pattern of other squares drawn as a small diagram inside it. The goal is to make every square light at the same time. The puzzle is ready below; the default flips each square and its four neighbours.

How to play

  • Clicking a square switches it between light and dark.
  • The same click also switches every other square shown in its small diagram.
  • You win when all squares are light at once.

Sizes and difficulty

The Type menu offers 3x3, 4x4 and 5x5 grids in two styles. Crosses flips each square and its up to four neighbours. Random gives each square its own random pattern, so every game plays differently. Custom sets any width, height and pattern style.

Solving tips

Order does not matter, and clicking a square twice cancels out, so each square is either clicked once or not at all. With crosses, use the 'chase' method: clear the top row by clicking the squares directly under its dark ones, repeat row by row, and see what is left in the bottom row. If you use Solve, it marks the squares to click in red, and clicking any other square adds a red mark showing it needs undoing.

Where this puzzle comes from

Flip is part of Simon Tatham's Portable Puzzle Collection, a set of about forty logic puzzles written by Simon Tatham and contributors and released under the MIT licence. Every grid is generated on the spot, so the supply never runs out, and for the grid-logic puzzles the generator makes sure each has exactly one solution, reachable by reasoning rather than guessing. The version here is the collection's own code compiled to WebAssembly; the Game menu can save a puzzle to a file and load it again, and the Type menu changes the size and difficulty.

Frequently asked questions

Does the order of clicks matter?

No. Each square ends up flipped by the total number of clicks that affect it, so only which squares you click matters, not the order.

Is this the same as Lights Out?

It is the same idea as the electronic game Lights Out, but here the goal is to turn every light on, and the random setting gives each square a different flip pattern.

Is Flip free to play here?

Yes, with no limit on the number of puzzles. Flip is open-source software under the MIT licence, and every grid is generated fresh when you press New game.

Does it work on a phone or tablet?

Yes. A tap works as a click and the puzzle resizes to fit the screen. Puzzles whose controls use the right mouse button are easier with a mouse.
