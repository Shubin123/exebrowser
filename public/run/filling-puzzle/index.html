Play Number regions puzzle (Filling) online Works — plays right here, unlimited puzzles

Guide updated October 2026 · Runs via WebAssembly (native port)

Filling is a number puzzle about areas. Some squares hold digits; you fill the rest so that every connected block of the same digit contains exactly that many squares. A 3 belongs to a group of three 3s, a 1 stands alone. The puzzle is ready below; click a square and type a digit, or drag to select several squares at once.

How to play

  • Write a digit from 1 to 9 in every empty square.
  • Each group of orthogonally connected squares holding the same digit must contain exactly that many squares.
  • Squares touching only at a corner are not connected.

This means two 1s can never be side by side, and two separate groups of the same number can only touch diagonally.

Sizes and difficulty

The Type menu has three sizes: 9x7, 13x9 (the default) and 17x13. There are no difficulty settings; bigger grids simply take longer. Custom lets you set any number of rows and columns.

Solving tips

Fill any square boxed in by finished groups first: if it cannot join a neighbour, it is a 1. When two equal digits sit close together, check whether joining them would make the group too big; if so, the square between them must be something else. A clue with only one way out must extend that way. Large numbers like 7 or 8 near an edge often have only one shape that fits.

Where this puzzle comes from

Filling is part of Simon Tatham's Portable Puzzle Collection, a set of about forty logic puzzles written by Simon Tatham and contributors and released under the MIT licence. Every grid is generated on the spot, so the supply never runs out, and for the grid-logic puzzles the generator makes sure each has exactly one solution, reachable by reasoning rather than guessing. The version here is the collection's own code compiled to WebAssembly; the Game menu can save a puzzle to a file and load it again, and the Type menu changes the size and difficulty.

Frequently asked questions

Can two separate groups have the same number?

Yes, as long as they do not touch along an edge. If two groups of 4 shared an edge they would merge into one group of 8, which breaks the rule.

What is this puzzle called elsewhere?

It is a Nikoli puzzle published as Fillomino. Filling is the name used in Simon Tatham's collection, which generates fresh grids.

Is Filling free to play here?

Yes, with no limit on the number of puzzles. Filling is open-source software under the MIT licence, and every grid is generated fresh when you press New game.

Does it work on a phone or tablet?

Yes. A tap works as a click and the puzzle resizes to fit the screen. Puzzles whose controls use the right mouse button are easier with a mouse.
