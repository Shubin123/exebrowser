Play Warzone 2100 online — the full game, free ▶ Runs in the browser — no install

Warzone 2100 is the 1999 real-time strategy game where you rebuild after a nuclear war: gather oil, build a base, research more than 400 technologies, and design your own tanks, cyborgs and aircraft from the parts you've unlocked. Pumpkin Studios made it, Eidos published it, and in 2004 its code and data were released as free software. A volunteer team has kept improving it ever since, and their official web build runs right here. Campaign, skirmish against the AI, and the tutorial: free, no install.

Start Warzone 2100 →

Opens full screen, in this tab. The first start downloads about 87 MB, which the game then keeps in your browser, so later visits start much faster. It needs a desktop or laptop browser with WebGL 2: recent Chrome, Edge or Firefox work best.

Where to start

  • New to it? Play the Tutorial from the main menu. It walks through trucks, oil, research and factories.
  • Skirmish is a single match against the AI on a map of your choice; it's the quickest way into a real game.
  • The campaign is three linked campaigns across a ruined Earth, and your base and research carry forward between missions.
  • Oil is everything. Send trucks to build derricks on every oil resource near you before anything else, then a research facility.
  • Design your own units. In the design screen, combine any body, propulsion and weapon you've researched.

Frequently asked questions

Is this the real Warzone 2100?

Yes. It is the official Warzone 2100 4.7.0 web build from the Warzone 2100 Project, unmodified except for how its files are delivered. The game was made by Pumpkin Studios and published by Eidos in 1999; its source and data were released under the GPL in 2004, and a volunteer team has developed it ever since. This site hosts a copy and is not part of the project.

What can I play?

The single-player campaign, skirmish games against AI opponents, and the tutorial. Online multiplayer isn't supported on this page; for that, install the game from wz2100.net. The campaign's video briefings aren't included either, so the game shows a notice that they're missing; dismiss it and play on.

How big is the download?

About 87 MB the first time, which takes a minute or two on a slow connection. The game keeps it in your browser afterwards, so later visits start without downloading it again.

Does it save?

Yes. Saved games are kept in this browser on this device. Use Continue Last Save on the main menu to pick up where you stopped.

Why doesn't it run inside this page like the other games?

Warzone 2100 runs several threads at once, and browsers only allow that for a page that is isolated from other sites. A game in a frame inside this page can't be isolated, so it opens in its own tab instead. See the notice for how it's hosted.
